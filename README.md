This repository contains the implementation of machine learning models and pattern recognition pipelines developed in Python. This was a collaborative academic project (Team 19) focusing on feature extraction, data transformation, and predictive modeling using ensemble learning techniques.

Project Components
Feature Extraction & Analysis: Utilized 2D Discrete Fourier Transforms to analyze spatial frequencies and extract meaningful patterns from the dataset.

Predictive Modeling: Trained and evaluated classification algorithms, specifically implementing Decision Trees and AdaBoost ensemble methods to improve predictive accuracy.

Data Processing: Handled data loading, preprocessing, and label mapping (utilizing .npy data structures) for model training and validation.

Technical Documentation: Co-authored a comprehensive technical report detailing the algorithmic architecture, mathematical foundations, and model evaluation metrics.

Technologies Used
Python

NumPy & Matplotlib (Data manipulation and visualization)

Jupyter Notebook (Interactive development)
